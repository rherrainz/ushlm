Copias WebP optimizadas, sin metadatos EXIF. Los originales no están en el
repositorio. Hay variantes de 480/800 px para las tarjetas y 1000/1600/2400 px
para la portada de escritorio, además de una composición vertical para móvil.
El recorte del auto excluye a la persona del fondo y cubre la patente.

Para cambiar las imágenes de una categoría, actualizar `offer_image.html`;
para paisajes complementarios, `destination_gallery.html`. No se requieren
migraciones ni servicios externos para cargar estas imágenes.
